Regulatory Edge Scoring — Methodology

Scientific reference

Each TF–target regulatory edge carries a confidence score (0–1) computed from a two-layer scoring system: a Random Forest model (primary, when available) and a heuristic weighted-sum fallback. These scores are prioritization metrics, not calibrated probabilities — experimental validation is always required.

Score Tiers

HIGH ≥ 0.75
Multiple independent evidence lines; ChIP or high motif + expression support. Suitable for hypothesis generation.
MED 0.50–0.75
Moderate confidence; database-curated or motif-only with partial expression support.
LOW < 0.50
Computational prediction only. Treat as exploratory leads only.

Random Forest Model (Primary)

A Random Forest classifier trained on known TF–target interactions from CoryneRegNet, using 8 multi-omics feature groups:

  1. Binding site strength (motif length / multi-site)
  2. ChIP-seq / ChIP-exo experimental evidence
  3. Expression correlation (transcriptomics)
  4. Database curation quality (CoryneRegNet label)
  5. Metabolic reaction coverage (iCW773)
  6. Metabolic pathway coverage (KEGG)
  7. Enzyme kcat median (DLKcat + BRENDA)
  8. Catalytic efficiency kcat/MW median

feature_missing_count in the CSV indicates missing features per edge. >4 missing features falls back to heuristic scoring.

Heuristic Fallback Score

Applied to sRNA edges and TF–target pairs outside the RF training set. Weighted sum of 4 evidence factors:

  • Binding Site Motif (w=0.25): multi-site: 0.78; long single-site (≥10 bp): 0.66; short: 0.48; absent: 0.0
  • ChIP Evidence (w=0.30): ChIP-exo: 0.95; ChIP-seq: 0.90; absent: 0.0
  • Expression Correlation (w=0.20): |Pearson r| for TF-TG; CopraRNA p/FDR/ΔG for sRNA
  • Database Curation (w=0.25): experimental: 0.86; curated: 0.74; predicted: 0.42

Formula: score = Σ(factor × weight) / Σ(active weights) + 0.06 × [≥2 factors > 0.1]

Data Sources

  • CoryneRegNet 7.0 — Curated TF–target interactions
  • iCW773 — C. glutamicum genome-scale metabolic model
  • ecCGL1 — Enzyme-constrained model (kcat via DLKcat)
  • BRENDA — Enzyme kinetics reference database
  • STRING v12 — Protein–protein interaction network
  • CopraRNA — sRNA target prediction (p-value, ΔG)

Research Limitations

  • Scores are relative prioritization metrics, not experimental probabilities.
  • RF model trained on C. glutamicum ATCC 13032 only.
  • sRNA–mRNA edges: heuristic-only (no RF coverage in this release).
  • Expression feature availability is fixed at model training time.
  • All interactions require experimental validation before publication.

iModulon Explorer

iModulons are transcriptionally co-regulated gene modules derived mathematically from big-data RNA-seq matrices using Independent Component Analysis (ICA). They represent biologically coherent signals responsive to environment and genetic perturbations.

iModulon Functional Categories

The 87 modules capture different regulatory layers of Corynebacterium glutamicum:

Metabolism
Core carbon pathways, nitrogen assimilation, iron uptake, and sulfur transport.
Stress Response
Acid/oxidative shock, envelope stress response, heat shock chaperones.
Regulatory / TFs
Sigma factor cascades, two-component signaling, direct TF-DNA regulons.
Uncharacterized
Novel co-regulation patterns of orphan genes waiting for functional validation.
